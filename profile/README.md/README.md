# BranchToBrowser

BranchToBrowser ships the last step of vibe coding: paste a public GitHub repo (Vite, React, or static Next.js) and get back a live link, a build README, and a project page — $19 flat, one-time.

**How it works:** paste your repo → free eligibility check (repos with databases, auth, or secrets are rejected before payment) → we build it, repairing common issues for up to 3 attempts → you get a live link + README + project page, hosted for 90 days. If an eligible repo can't ship after 3 attempts, full refund.

**Status:** founding pilot — 10 spots, every repo manually reviewed. No customers yet; this is the honest ground floor.
